

一、 页面功能分析与功能设计

下面是各个页面需要你用 C++ 底层去实现的功能说明（你可以把这个作为开发需求文档）：

👑 全局顶栏 (Top Bar)

  - 手动/自动 滑块：全局状态机切换开关（具体限制见第三节）。
  - 心跳灯 (绿)：后台起一个 QTimer，每 500ms 取反一次颜色；如果检测到运动卡掉线，变为灰色。
  - 急停灯 (红)：常态为暗红色，当接收到物理急停信号或驱动器报警时，高亮闪烁，并触发底层急停指令。

🌟 页面 1：自动运行 (AutoRun)

  - 视觉画面 (左侧)：通过奥比中光 C++ SDK 获取 RGB 帧和深度帧，转化为 QImage，实时在 QLabel 上刷新。
  - 节拍与产量：CT 需要在后台代码中记录一个动作循环从开始到结束的时间差；产量在每次放置动作完成后 +1。
  - 状态与坐标：监听后台核心控制线程，实时刷新 X,Y,Z,R。
  - 四大主控按钮：
      - 【启动】：触发读取当前选中的 JSON 方案，并启动后台 C++ 执行线程。
      - 【暂停】：调用控制卡的暂停指令，冻结当前流程指针。
      - 【停止】：中止流程，机器人回退到安全位置。
      - 【急停(软)】：直接切断伺服动力，流程强制终止。

🛠️ 页面 2：手动控制 (Manual Control)

  - 全局使能/断使能：一键遍历 6 个轴，发送 ServoOn 或 ServoOff 指令。
  - 点动功能 (JOG)：
      - 按住 [+] 触发 pressed 信号 -> C++ 调用 MoveVelocity(axis, speed)。
      - 松开 [+] 触发 released 信号 -> C++ 调用 StopAxis(axis)。
  - 绝对移动 (Go)：点击后读取输入框的值，C++ 调用 MoveAbsolute(axis, target, speed, acc, dec)。
  - 特殊轴处理：轴2和轴4（舵机），底层是串口发指令；轴5和轴6（夹爪、挤出）注意方向的正负逻辑。

📝 页面 3：工艺与流程 (Process Edit)

  - 方案切换：读取 config.json 里的字典键值，更新到下拉框。点击【确认切换】后，刷新左侧动作列表。
  - 单步执行：极为关键的调试功能。C++ 线程执行完一个动作后进入 wait() 挂起状态，点击该按钮触发 wake() 唤醒执行下一步。
  - 示教功能 (读取当前坐标)：点击后，抓取当前机器人的实际 X,Y,Z,R 值，自动填入右侧表格的当前选中行中。
  - 保存动作：将左侧列表和右侧表格的数据，序列化为 JSON 字符串，覆写保存至磁盘。

⚙️ 页面 4：设备与配置 (Config)

  - 这里的输入框，在界面初始化时要从 config.json 里回显数据；修改后失去焦点或点击连接，要将数据写回。
  - 九点标定按钮：触发一个独立的自动寻点标定序列，配合视觉算出 4 \times 4 齐次变换矩阵，并保存在本地。

二、 全局参数限制设计 (互锁逻辑 Interlock)

这是工业软件的灵魂，也就是你提到的“手动/自动模式切换到底有什么用”。你必须在 C++ 代码中严格实现以下权限隔离，否则极其容易引发撞机事故！

🔒 模式 1：处于【自动】模式下

  - 理念：只允许机器人跑预设的程序，禁止人为干预硬件位置。
  - 界面限制：
      - 【自动运行】页：【启动】按钮激活可用。
      - 【手动控制】页：**全页禁用！**所有的使能、断使能、点动(JOG)、绝对移动(Go) 按钮必须 setEnabled(false)（变灰）。
      - 【工艺与流程】页：【单步执行】禁用；【读取当前坐标(示教)】禁用；【保存动作】禁用（防止运行中改方案导致崩溃）。
      - 【设备与配置】页：修改参数的输入框变为只读；【执行九点标定】按钮禁用。

🔓 模式 2：处于【手动】模式下

  - 理念：工程师调机状态，允许任意活动，但禁止流水线自动生产。
  - 界面限制：
      - 【自动运行】页：【启动】按钮必须禁用（变灰）。可以按【复位】或【初始化】。
      - 【手动控制】页：所有轴的点动、绝对定位全部激活可用。
      - 【工艺与流程】页：【单步执行】可用；允许示教写点、允许修改保存方案。
      - 【设备与配置】页：允许参数修改、允许跑标定程序。

🚨 特殊状态：触发【急停】或【断联】时

  - 理念：最高级中断，无视手动/自动模式。
  - 界面限制：
      - 无论哪个页面，所有的运动控制按钮（启动、JOG、Go、单步、标定）必须瞬间全部变灰禁用。
      - 直到急停解除，且操作员点击了【清除报警】或【复位】，系统恢复正常状态后，才根据当前的“手动/自动”拨动开关重新分配权限。
