## 一、术语与状态速查（执行前必读）

本节供真机执行时快速对照，避免靠"感觉"判断状态。

### 1.1 `SequenceWorker::WorkerState` 四态速查

| 状态 | 含义 | 触发方式 | 自动页五钮表现（gate=true 时） | 典型日志 |
|---|---|---|---|---|
| **Idle** | **没有会话在执行**（引擎空闲） | 上电默认 / 跑完 / 停止 / 清报警后 | 启动/继续=按 homed 决定、**暂停灰、停止灰、清报警可点、初始化可点** | `state -> 0 reason 0` |
| **Running** | 正在执行动作 | 点「▶ 启动/继续」、`RunSafePos()` | 启动灰、**暂停可点、停止可点**、清报警灰、初始化灰 | `state -> 1 reason 0` |
| **Paused** | 挂起且保留上下文 | 点「⏸ 暂停」、单步等下一步 | **启动/继续可点（继续）**、暂停灰、停止可点、清报警灰、初始化灰 | `state -> 2 reason 0/1`（0=用户暂停，1=单步等待） |
| **Fault** | 上次失败且未清除（**软件锁存**） | 动作失败（如 IK 不可达） | 启动灰、暂停灰、停止灰、**清报警可点**、初始化可点 | `state -> 3 reason 0` |

- `IsRunning()` 定义为 `state != Idle` → **Idle = 引擎没持有任何会话**。
- 让引擎离开 Idle 的只有三条路：自动流程 `RunSequence`、单动作 `RunSingleAction`、**安全位 `RunSafePos()`**（回零后自动回安全位期间也是非 Idle）。

### 1.2 `Idle` **不等于**什么（真机最易混淆）

- Idle **≠ 已使能** —— 使能是 `HardwareManager::axisEnabled_`，另一套状态
- Idle **≠ 已回零** —— `homed` 也是另一套（所以 Idle 时「▶ 启动/继续」仍可能因未回零而灰）
- Idle **≠ 无故障** —— 故障是独立的 `Fault` 态；Idle 只表示"当前没在跑"
- Idle **≠ 轴静止** —— 手动页点动不经过 worker，轴在动而引擎仍可以是 Idle

### 1.3 真机上如何确认"当前是 Idle"（按可靠度排序）

1. **日志**最近一条是 `[SequenceWorker] state -> 0 reason 0`（0=Idle、reason 0=None）——最准
2. **自动页五钮矩阵**：暂停灰、停止灰、清报警可点、初始化可点
3. ⚠ **不要用状态标签判断**：`UpdateStatusByState` 的 Idle 分支**故意不覆盖标签**（`AutoRunPage.cpp:622-624`），为保留「✅ 完成」「⏸ 中断」等终态。所以 Idle 时标签显示的仍是上一次的终态，**不是**"空闲"

### 1.4 上升沿 / 电平语义（安全位自动触发的关键，详见 `doc/global_safe_position.md` 三节）

- `homeStateChanged(bool homed)` 是**电平语义**：只要"全轴 homed"成立就会 emit true，**单轴重回零（其余轴 homed 保持）会重复 emit true**。
- MainWindow 用 `lastHomed_` 造**上升沿**（`rising = homed && !lastHomed_`），只有"从 false 跳到 true"那一次才回安全位。
- **一句话记忆（TR-081 真机确认）**：**自动回安全位 = 软件启动后的第一次一键回零**；此后再回零一律不触发——因为 `axisHomed_` 只在"启动初始化 / 回零被中断"才清，手动移走、急停、断使能**都不清**，`lastHomed_` 恒 true → 无上升沿。用例 9.9（全轴重回零）、9.12（单轴重回零）、9.11（Paused 重回零）实测一致。
- **若未做上升沿**：操作员单独回零 J1 时也会触发一次安全位走位 → 危险。用例 9.12 专测此回归。
- **急停锁存同理**：不能用 `IsSystemHomed()` 判定急停是否恢复（TR-062：`AbortHoming` 只复位"回零中"的轴）→ 用 `estopPending_`（TR-075）。

## 五、验收标准

1. **五钮矩阵**：Idle / Running / Paused / Fault / 非自动模式 / 急停锁存 六种情形下与 `UpdateControlsEnabled` 表完全一致，无"该亮不亮/该灰不灰"。
2. **暂停续走为原地续走**：续走瞬间四轴单调趋近当前点绝对目标，不回退、不重跑整个动作；停止为全轴减速停且**保持使能**（不重新使能即可再启动）。
3. **安全位**：示教数值落盘且两位小数与轴读数一致；手动/自动触发均**先动 Z 到安全位 Z、再动 J1/J2/R**；`enabled=false` 与 `worker not idle` 两个跳过条件均生效；安全位会话不污染工艺页列表选中行。
4. **互锁**：启动默认手动；自动模式白名单 {自动运行, 视觉检测} + 强制跳页 + 视觉页 9 控件只读、操作类仍可用；Running/Paused 弹窗 + 回弹无递归；Fault 放行；单步会话切自动强制清理且无残留。
5. **急停全链路闭环**：急停 → 红字① → 切手动 → 使能 → 黄字② → 回零 → 绿字③ + 自动回安全位 → 切自动 → 可启动；期间五钮始终全灰（锁存不被使能有效绕过）。
6. **循环生产（TR-091，第四批）**：默认「单轮」时与 8.17 逐字节一致（**无 `=== 循环` 日志**、「✅ 完成」只出现一次）；N 次/无限循环的计数、终止、暂停续走符合方案 §五/§六；**`schemeFinished` 只在全部循环完成时发一次**；循环间隔回安全位**严格先抬 Z 到位再水平移动**（点1 日志出现 `skip axis J1/J2/R (in position)`、J1/J2/R **零位移**）；未启用安全位时拒绝启动；无限循环需二次确认。

7. **P1~P4 实施验收（TR-097~100，第六批，阶段 11）**：① `confidenceThreshold` **真的在过滤**（11.1~11.2 三档阈值自洽）；② 编号升级**惰性 + 幂等**、删除**不复用**编号（11.7~11.9）；③ 三格同刷且渲染不卡（11.12/11.14）；④ 自动运行期间相机开关置灰、视觉页「停止采集」不打断自动运行（11.25/11.26）；⑤ 真机拔插 10 次自动恢复、10 min 长稳、D2C 软对齐生效（11.31/11.32/11.35）。

8. **P5 视觉引导动作（TR-101，第七批，阶段 12）**：① 编辑期校验拦住「未选择 / 悬垂引用 / 跨方案」三种非法引用（12.8~12.10）；② 执行期取不到识别结果时**明确报错且零运动**（12.11 / 12.12）；③ 日志可验证「先上方、后目标」，且第 2 段**只下发 Z**（`skip axis J1/J2/R (in position)`，12.13）；④ 构造点的 `r` 只跟 `guideR` 走、**与 `PuffResult.yaw` 无关**（12.14）；⑤ 循环生产每轮重新识别，引用**不受插入 / 删除 / 重排影响**（12.18 / 12.19）。

9. **P6 动作树与分组并发（TR-102，第八批，阶段 13）**：① 组内冲突**按资源不按类型**拦截，且 `Delay` 不设限（13.13 / 13.14）；② **数据依赖**（识别 + 引用它的视觉引导同组）与**嵌套分组**各被拦一次（13.15 / 13.16）；③ 组内并发是**同时下发、统一汇合**，节拍 ≈ 最长子动作而非各子动作之和（13.19 / 13.30）；④ 组内**暂停冻结延时计时**、**停止等到位才返回**、**单步以整组为一步**（13.22 / 13.23 / 13.24）；⑤ 失败归因 = **首个失败者**，且不被误报为「用户停止」（13.21）；⑥ 键名 `actions` → `nodes` 与 `nodeType` 落地，**旧键仍可读、升级惰性**（13.3 / 13.4）。

## 六、风险与注意事项（真机安全）

1. **关 wifi**（最高优先级）：`MC_Open` 在 wifi 开启时失败（code=-6）；pcIp 须真实网卡 IP 与 192.168.0.1 同网段。
2. **减速停距离不是缺陷**：暂停与「■ 停止」都是 `MC_Stop` 斜坡减速，**J1 高速约 9°**；点位与障碍物须预留该距离。不可接受时后续走 `MC_SetStopDec` 调档，**不要改断脉冲**（开环会惯性滑行丢步）。**点动松键与暂停/停止同档**（TR-085：`StopJog` 与 `StopAxis` 同一 `MC_Stop(mask,0)`），同样有滑行且 `jogSpeed==maxSpeed` 时距离相当；需更短停先降点动速度，调 `MC_SetStopDec` 须防与自动流程并发改档（排跨页互斥之后）。**→ TR-090 已落地**：config 每轴 `stopDecSmooth`（系数 0.1~2，卡默认 0.5；0=不下发）+ 设备配置页「停止减速度」输入框，`MoveAbs/MoveJog` 前去重下发；**真机标定从 1.0 起逐步调大，过陡丢步即回退**；启动日志看 `[BoPaiCard] SetStopDec ... cardSmoothPrev=...` 反读卡端默认验证语义。
3. **续走路径变更**：Resume 重发**当前点绝对目标 MoveAbs**，不经过原轨迹 → 续走前目视确认中途无障碍。
4. **安全位第一段不一定是"抬 Z"**：点 1 = `{当前 J1, 当前 J2, safePos.z, 当前 R}`；若当前 Z 高于安全位 Z（电机坐标 0 最高、向下为负），第一段实为**下降** → **示教安全位时 Z 必须取行程上部的值**，否则从高位触发会撞下方物体。
5. **急停后坐标不可信**：断使能 → J2/R 可能垂落；开环无编码器。**禁止急停后续走/启动**，必须走完整恢复链。
6. 急停期间手远离机构（J2/R 失力可被拨动）。
7. **单一运动源**：安全位会话与自动流程共用 worker（running 门禁互斥），但**手动点动与 worker 并存风险未收口（TR-066）** → 任何 worker 非 Idle 期间禁止在手动页点动/Go/单轴回零。
8. **config 落盘路径陷阱**（§3.3）：示教写输出目录 config.json，重建会覆盖 → 示教后立即备份，阶段 10 前复查 `enabled`。
9. **安全位会话无法软中断**（§0-B）：危险时**只能按顶栏【急停】**，测试时手必须在急停按钮旁。
10. **制造 Fault 只准用"不可达点"**（IK 在运动前失败，无实际运动）；**严禁撞限位/堵转**。
11. 无真实相机：10.3/10.4 只验证控件可编辑性，不验证相机功能。
12. 软限位与夹具/线缆干涉（§3.1）。
13. **日志取证**：判定以 `log/creampuff.log` 为准，UI 提示为辅助；每条用例前记录时间戳，便于定位 `state -> N reason N` 序列。
14. 每阶段验收不通过即停；定位前先读 `TEST_RECORD.md` 防回归（`AGENTS.md` 硬规约）。
15. **循环生产专项（TR-091，第四批）**：① **循环间隔回安全位是刚需**——结束位直奔下一轮起点会多轴同时 `MoveAbs` 横扫桌面；未启用安全位且勾选「回安全位」时程序**拒绝启动循环**，勿用配置绕过；② **无限循环必须二次确认**（急停在手边 / 工作区无人员肢体 / 软限位已核对），确认框不可习惯性点「是」；③ 跨轮前目视确认安全位 Z 取行程上部（同第 4 条：安全位 Z 若低于当前 Z，第一段实为**下降**）；④ 长循环日志：`log/` 按日期分文件、**保留 7 天**，跑无限循环前确认磁盘余量；⑤ 循环运行期间**只能**用自动页「■ 停止」终止（切手动被互锁拒绝；一键回零在手动页 → **物理不可达**，故不设该用例）；⑥ 循环间隔回安全位的 Z 到位判定是**时间估算**（`距离/速度 + 200ms`，开环无反馈），非位置确认——8.20 必须核验点1 只下发 Z。
16. **J1 开环丢步风险（TR-095，2026-09-15 真机发现）**：J1 = 开环步进 + 100:1 减速，输出 30°/s ≈ 电机 500 rpm 已在失步高发区；生产方案 100% 速度 + 每轮 102° 大行程加减速 → **同向丢步逐轮累积**；开环读回=指令计数，**丢步后软限位/安全位/日志全无感知**。**生产方案速度建议 ≤70%**；**长循环/无人值守生产前必须重新一键回零**（回零开关重建基准）；发现臂位漂移先按 8.27–8.29 判别。`stopDecSmooth`（TR-090）只管 `MC_Stop` 停止档，正常运动加减速走 config `maxAccel`（J1 现 200）。
