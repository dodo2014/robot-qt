## 修复 1：手动页连接状态分段着色
- 现象：急停旁「运动卡/舵机」连接状态未连接/已连接都显示绿色
- 根因：(cardOk || servoOk) 整条统一着色，任一在线即全绿
- 修复：QLabel 富文本 span 分段着色（ManualControlPage::OnConnectionChanged）——未连接黄 #e0a520、已连接绿 #7ed67e
- 真机验证：通过

## 修复 2：全局使能连接门禁
- 现象：运动卡未连接时点「全局轴使能」，4 个电机轴状态灯误变绿
- 根因：EnableAll 只判指针非空（if (motionCard_)），未连接时底层 EnableAxis 仍返回 true → axisEnabled_ 被置 true
- 修复：
  - HardwareManager::EnableAll 入口加门禁：任一硬件未连接直接拒绝，axisEnabled_ 保持全 false → 状态灯显示未使能
  - UI 判据 card || servo 改 AND，提示「未连接硬件，命令可能无效」（警示黄）
  - DisableAll 不设门禁（断使能属安全操作）
- 真机验证：通过（断网线点使能被拒 + 黄色提示；恢复连接后流程正常）

## 补充（8-25 下午）：舵机软件掉线防误判 + 重连引导
- 真机现象：设备运行中舵机"掉线"→1s 全量重连→重连后点动被门禁拦，需断使能+再使能恢复
- 根因：① Transaction 响应解析遇脏字节固定比较 rx[0..1] 不丢弃 → 必超时；② 校验失败立即放弃；③ 单次查询失败即 online=false，连续 4 tick(1s) 即全量重连——EMI/USB 抖动的瞬时坏帧被放大成离线
- 修复：滑动字节对齐 + 校验失败丢一字节继续等帧；ReadTelemetry 失败重试 1 次；超时 40→60ms；离线阈值 2s 且重连前 Ping 门卫（IAxisServo 新增 Ping()），Ping 通不重连
- 重连后无法点动 = 门禁正确行为（扭矩已释放须人工确认）；不做自动使能；UI 边沿提示「舵机已重连，请重新执行全局轴使能」；直接点全局使能即可恢复（无需先断使能）
- 待真机复测：运行中不再频繁出现 reconnect 日志
