### TR-073 自动运行页 5 按钮 + SequenceWorker 显式状态机

- **AutoRunPage 按钮组重排为 5 钮**：▶启动/继续、`⏸暂停`、`■停止`（=StopImmediate 减速停保持使能）、`↺清报警`（=ClearFault，替代原「复位」——原复位实为 HomeAll 已归手动控制页）、`⟳初始化`（仅 Initialize，不含回零，分级引导去手动页使能/回零）。
- **SequenceWorker 显式状态机**：`enum class WorkerState{Idle,Running,Paused,Fault}` + `PauseReason{None,User,Step}`；信号 `stateChanged(WorkerState,PauseReason)` 取代原 QString 四态中文字符串（全工程原 6 处 emit、0 处 connect 已补齐）。
- **点级暂停 + 原地续走**：`Pause()/Resume()` + `PauseGate` 点边界挂起（stepGatePending），暂停时运动原地停、续走从暂停点继续（回抽反向补料方向与语义更自然，故选点级暂停而非重试整个动作——与用户/Gemini 共识）。
- **StopImmediate()**：cancel + 全轴减速停（`StopAllAxes`）、保持使能；`Stop()` 语义不变（仅置 cancel 就近跑完当前动作，留给单步/ShutdownWorker）。
- **Fault 锁存**：动作失败且非 cancel → 进入 Fault 态保持，需 ClearFault 回 Idle（ClearFault 只清软件状态，不碰硬件使能——与急停断使能区分）。
- **隐患修复**：`RunSequence` 补清 `stepMode`（否则单步会话残留会让后续安全位会话卡死在 Paused(Step)）。

### TR-074 全局安全位

- **config 新增** `kinematics.safePos.{j1,j2,z,r,enabled}`（关节角形态，与示教 joints 同坐标系、无 IK 歧义；j3=Z 电机坐标；enabled 默认 false，示教后自动 true）。
- **RunSafePos()**：读 config 构造 2 点临时方案（点1=原地抬 Z、点2=安全位关节角）走既有 `RunSequence→ExecuteMove`——零新运动代码，天然获得暂停/停止/门禁/与自动运行互斥；`IsSafePosSession()` 供 UI 区分临时方案。
- **自动触发**：回零完成 `homeStateChanged(true)` 由 MainWindow 取**上升沿**（`lastHomed_` 电平判定，单轴重回零会重复 emit 故需上升沿）触发自动回安全位；worker Idle 守卫防重入。急停恢复链路闭环：急停 → 切手动 → 使能 → 一键回零 → 自动回安全位。
- **ManualControlPage**：顶栏新增「回安全位」「示教安全位」两按钮；`SetSequenceWorker` 注入 worker；示教读四轴关节角写 config 并自动启用。
- **ConfigPage**：运动学区新增安全位 J1/J2/Z/R 输入框 + 「回零后自动回安全位」开关（现读 config，不 emit paramsChanged）。
- **ProcessPage**：`actionStarted` 加 `IsSafePosSession()` 守卫，防临时方案误选列表行。
