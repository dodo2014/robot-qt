## 坐标面板 R 折行问题（排查后暂不处理）

- **现象**：窗口/右侧分屏缩小后，自动运行页坐标面板 (X,Y,Z,R) 显示不全；此前调整（字号 16→14px、开启 `setWordWrap(true)`）解决了裁切，但宽度不足时 `R: 0.00°` 折行到第二行。
- **根因**：`m_coordPanel` 是**单 `QLabel` 承载 4 个坐标值** + `setWordWrap(true)`——宽度不够时 Qt 在空格处折行；关掉换行则回到裁切（显示不全）。单标签方案下折行/裁切二选一，无两全。
- **修复方案（代码曾实现，用户手动回滚）**：拆成 X/Y/Z/R **4 个独立 `QLabel`**（各 `setWordWrap(false)`）放入容器 `QHBoxLayout`——每个轴值是原子单元，布局给各标签自然最小宽度，整体既不折行也不裁切。`MainWindow` 已有 `setMinimumSize(1200,700)`，折行多发生于分屏拖窄场景。
- **裁定（2026-09-04 用户）**：不影响功能、仅样式，**暂不处理**；后续如需修复按上述方案实施。已记台账 **TR-071**（注：TR-070 已被同日的舵机连接状态修复记录占用）。

## 舵机未上电误报「已连接」修复（TR-070，2026-09-04）

**现象**：舵机仅插 USB 未接电机电源，启动软件 UI 显示「舵机: 已连接」。用户日志实证另一 bug：上电启动时 `WriteUserData id=1` 两次、`Servo id 1 online` 两次，id=0 从未被探测。

**根因三层**：

1. `XRServo::Connect` 串口打开成功即返回 true，Ping 失败仅打 WARN；
2. `XRServo::IsConnected()` 语义 = 串口句柄有效，真实在线状态在 `IsOnline()` 但未接入"已连接"判定；
3. `HardwareManager::IsServoConnected()` 只查串口级 → UI 标签、EnableAll 门禁、PollTick 边沿检测全基于假"已连接"。

**探测 id 时序 bug**：`Initialize`/`ReconnectServos` 先 `Connect` 后 `SetServoId`，而 Connect 内部用默认 id=1 做 Ping/WriteUserData(addr=44)——J2(id=0) 的在线标志实际靠 ping id=1 判定。

**修复**（单文件 `HardwareManager.cpp` 三处）：

- `IsServoConnected()` 收紧为「串口打开 且 所有已创建舵机 `IsOnline()`」（SimServo 的 IsOnline==connected_，仿真不受影响）；
- `Initialize`/`ReconnectServos` 中 `SetServoId`/`SetSpeed` 移到 `Connect` 之前。

**验证**：Debug + Release 编译通过；Sim 冒烟 SMOKE_INIT_COMPLETE=True（日志时序证实 SetServoId 先于 Connect）；真机验证通过（2026-09-04 用户确认）：未上电显示"未连接"、上电 ~2s 自动恢复"已连接"、使能门禁正确拒绝。

**已知开口**：软件开着时上电、经「Ping ok skip reconnect」路径恢复的不重写 addr=44 accel 参数（舵机用户数据预期掉电保持）；真机点动若顿挫回归，再在恢复边沿补写。

## 示教记录关节角 + 确定性执行（TR-071，2026-09-04）

**需求**：工艺流程页示教坐标时，process.json 没有记录关节角度（排查发现旧版 save 硬编码写 `joints{j1..j4}=0.0` 占位，真实关节角从未落盘）；且执行一律 InverseSmart 就近选解，示教姿态不被复现。

**设计（用户逐项确认）**：

- `PointData` 加 `hasJoints/j1~j4`；**j3=Z 电机坐标**（回零后=0，与 coord.z 末端高度差固定偏移 Z0−h1−tcpDown=165——两坐标系语义经用户确认区分，若混用执行会撞顶）；j4=R 角；j1/j2=逻辑关节角
- 示教读取时记录四轴关节角；执行时点位带有效 joints → 直接按关节角运动（日志 `Teach joints →`，无 IK 双解歧义）；无 joints → 现状 InverseSmart
- 手改坐标保存 → joints 作废（**json 删除字段**而非置 0——0 是合法关节角无法区分作废）
- 执行层 FK 一致性校验（±0.5mm/0.5°）：joints 与 coord 不匹配 → 回退 IK，拦截旧版全 0 占位残留数据（fill_start 等模板点若采信 J(0,0,0) 会走到 (358.69,0,165)）

**实现**：ProcessManager（纯数据层 load/save）、ProcessPage（示教记录 + OnSaveAction 容差 0.006 比对继承/作废）、SequenceWorker::MoveToPoint 三分支共用下发段。posture 字段语义不动。

**验证**：Debug+Release 编译通过（LNK1168 结束进程重编）、Sim 冒烟 SMOKE_INIT_COMPLETE=True；**真机验证通过（2026-09-04 用户确认）**：示教新点 json 出现 joints 且 j3=Z 电机坐标、带 joints 点执行日志 `Teach joints →` 姿态复现、手改坐标保存后字段消失执行 `IK →`、旧全 0 模板点 `mismatch, fallback to IK` 位置正确。TR-071 收口 🟢。
