## 补充（8-26）：一键回零被软限位误杀（根因分析 + 修复）
- 现象：一键回零报「轴1到达软限位 / 轴6到达软限位」运动停止，但轴1未触碰原点开关；昨天 J1/Z 单轴回零偶发同源
- 根因链（三层叠加）：
  1. J1 未回零时逻辑位 = 机械规划位 0 - offset 102 = **-102 恰好压 limitMin(-102) 边界**
  2. PollTick 回零完成检测是**单拍判定**：`homingActive_[i] && !st.running` 任一拍 running=false 即清保护；而 MC_HomeStart 到卡端 running 置位存在启动间隙（含 Start=1 时 HomeStop+150ms 重试窗口）→ 保护被提前误清
  3. inverted 轴回零搜索方向恰朝越界侧：物理正向搜索 → 逻辑位置向负走 delta<0 → 「越下界且 delta≤0 + running + 非回零保护」全满足 → StopJog 杀掉回零
- 轴6（挤出）同源：HomeAll 对未接电机轴也发 HomeStart，位置恒 0 压 limitMin=0 边界
- 修复：homeStartedMs_[ai] 记录发起时刻，完成检测加 **1s 最短保护期**——发起后 1s 内 running=false 不判完成
- Debug+Release 编译通过、独立窗口冒烟存活；待真机复测一键回零全轴正常完成
