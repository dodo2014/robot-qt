## 强制开机回零互锁（Homing Interlock，16:28-17:45，第二道安全门禁）

**背景**：用户提供 Gemini 建议——J1/Z/夹爪/挤出为**开环步进电机，断电丢绝对坐标**，未回零前软件"以为"的坐标与机械实际不符，发绝对定位可能撞机（急停是事后补救、回零是事前保障；类比"刹车 vs 地图"）。互锁分层（禁绝对定位/自动运行、放行 JOG 脱困/使能/回零）符合工业标准，与既有 `IsGlobalEnabled` 使能门禁同构，作为第二道门禁实现最自然。

**第一轮实现（16:28）**：`HardwareManager` +`IsSystemHomed()/IsAxisHomed()/homeStateChanged` + `axisHomed_`（无绑定轴恒 true）+ `MarkAxisHomed`（HomeAxis 成功分支置位）；`MoveAbs` 入口加回零门禁（JOG/回零不受限）；`RunSequence/RunSingleAction` 加同门禁（errorOccurred「系统未回零，请先一键回零」）；AutoRunPage 启动按钮初始禁用+联动；ProcessPage 单步/执行选中按钮联动+双保险弹窗；ManualControlPage Go 失败提示。踩坑：Edit 缩进不匹配曾破坏 HomeAxis 结构，整体重写修复。6 文件，Debug+Release 编译通过、Sim 冒烟存活。

**漏洞修复（17:00，用户真机实测发现）**：启动→使能→一键回零（中途急停）→重新使能→**手动 Go 成功运动（错误）**。根因：`HomeAxis` 在**成功下发回零指令后立即 MarkAxisHomed**——回零异步（指令即返回、运动在后台），HomeAll 瞬间把全部绑定轴标「已回零」；急停只清 homingActive_/使能/忙态、**不清 axisHomed_** → `IsSystemHomed()` 恒 true。修复（完成判定从「指令下发」挪到「轴实际到位观测」）：① HomeAxis 不再置 homed，只置 homingActive_+homeStartedMs_；② 卡轴完成 → `PollCardAxis` 既有检测点（homingActive_ && !st.running && 过 1s 保护期）→ MarkAxisHomed；③ 舵机完成 → `PollServoTelemetry` 新增（homingActive_ && |逻辑角|≤1°）→ MarkAxisHomed；④ 新增 `AbortHoming(ai)`（回零被打断 → 回零中绑定轴 homed 复位，部分完成不算完成；已回零完成轴保持）接入 EmergencyStop/DisableAll/StopAxis/StopJog。

**轴6 豁免（17:23，用户确认只接运动卡未接电机）**：`AxisConfig` 加 `enabled`（默认 true）+ config `Axis_Extruder.enabled=false` → 初始化 **SetBinding(None)**（显式覆盖防 AxisMap 默认表兜底回 Card）+ `HomeAll` 跳过 None 轴（`IsGlobalEnabled` 既有逻辑本就跳过 None）。轴6 不参与回零互锁/使能/回零/运动判定，接电机后改 config 即恢复。

**启动崩溃修复（17:42）**：真机启动断言崩 `QList::operator[] index out of range`（qlist.h:518）。根因：enabled 豁免实现时在 `LoadAxisConfigsFromConfig`（Initialize 第 4 步）写 `axisHomed_[i]=true`，但 `axisHomed_` 的 resize 在第 5 步——空 QVector 越界。删除该行（第 5 步统一初始化在 SetBinding 之后，None 轴自动保持 true）。教训：**Initialize 分步初始化，前序步骤禁止访问后续才 resize 的成员容器**；Sim 冒烟 SMOKE_ALIVE=True 曾因断言框挂起进程误报，验证须查日志 `Initialize complete`（17:45 已确认，Sim 日志 SimCard Axis 0/1/3 无 Axis2 证明轴6 豁免生效）。
