## 1.2 结论分析
- 卡轴（J1/Z/夹爪）：逻辑 = 机械规划位(上电 0) − offset → 未回零即显示 -offset（J1=-102），与回零后相同，无法区分是否已回零（设计行为，非 bug）
- 舵机（J2/R）：绝对编码器，逻辑 = 遥测真实机械角 − offset，无"回零"概念
- 处置：real_machine_plan_phase2.md 与 kinematics_sequenceworker_test.md（H01 加 ±1 度容差）预期已修正

## J2 回零精度分析（1.4）
- 回零实现 = MoveToAngle(0,0) 软件回零（舵机无原点开关），FashionStar 死区约 1.5 度 → 实际停在 0.6~0.7 度
- 三次波动 ±0.3 度与 **J2 电机外金属套松动**相关 → 决定先紧固再复测
- 暂不软件补偿：0.6 度 ≈ 小臂末端 1.7mm，可接受

## Bug 修复：J2/R 回零"卡回零中"阻塞 jog/Go
- 现象：舵机回零机械停止后状态一直"回零中"，点动/Go 被拦，必须点停止才能恢复
- 根因：servo 轴 homingActive_ 只能靠 PollTick 卡轴 st.running 清除（舵机不在卡轴状态向量中），永不清除
- 修复：
  - HardwareManager::CheckAxisBusy busy 超时时同步清 homingActive_ 并 emit axisMoveFinished（HardwareManager.cpp 兜底）
  - UI 层 homingAxes_ 向量由 axisMoveFinished 驱动提示更新：超时显示"回零完成"、点停止显示"回零已停止"、状态点紫色"回零中"
- 记账：TEST_RECORD.md「手动页回零状态提示（UI 层，2026-08-24）」
