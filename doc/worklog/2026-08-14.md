### 2. 软限位"惯性超界后反向无反应"修复（核心，与 J1 同源）
- **现象**（真机夹爪）：点动夹紧惯性冲到 `0.2`（>limitMax=0）后，持续按住「松开」无反应，只能一点点按才回界内；位置 0.2 时 Go 到 -3 也无反应。松开撞 -5 到 -5.2 同理。
- **根因**：`HardwareManager::PollTick` 软限位拦截只看 `position 越界 + running`，**不看运动方向** → 惯性超界后轴一 running（哪怕正朝边界内走）就被 `StopJog`，每 50ms 打断，故持续点动/Go 均无效。
- **修复**：按逻辑位置增量 `delta = st.position - lastPollPos_[i]` 判断运动方向，**仅拦截"仍朝越界方向运动"**（越上界 delta≥0 / 越下界 delta≤0），**朝边界内运动放行**。新增成员 `lastPollPos_`（`HardwareManager.h`），`Initialize` 用 `GetPosition` 初始化基线避免首轮误判，每轮 `PollTick` 更新。
- **影响轴**：J1（软限位 0~90）与夹爪一并受益；`MoveAbs/MoveJog` 入口校验本就按目标/方向判越界，无需改。
- **编译**：Debug + Release 均 EXIT 0。仿真冒烟（临时切 SimCard）启动存活、初始化正常（SimCard 为规划位置无机械惯性，此问题无法在仿真复现，最终验证靠真机）。
