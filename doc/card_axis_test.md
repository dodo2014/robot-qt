> 配套代码修复记录见 `AGENTS.md`「电机轴真机测试」。

## 前置准备

1. **接线核对**（务必按下面表，AxisMap 现由 config `portId` 驱动）：

   | 逻辑轴 | 电机-卡 axis | home | config `portId` | 说明 |
   |--------|--------------|------|-----------------|------|
   | 轴1 J1 | axis1 | home1 | 0 | 大臂 |
   | 轴3 Z  | axis2 | home2 | 1 | Z 升降 |
   | 轴5 夹爪 | axis4 | home4 | 3 | 夹爪 |
   | 轴6 挤出 | axis3（未接） | 无 | 2 | 本轮不测 |

   > 关键：**第 N 轴的机械原点开关必须接 home N 端子**（BoPai 卡 home 输入按轴号固定，软件不可改映射）。轴6 电机线/Home 均未接，BoPai 卡 axis3 保持空置。
   > 本次已将 config `portId` 改为与接线一致，并让 `AxisMap` 从 config 读映射（不再用旧硬编码轴号）。

2. **已确认机械参数**（驱动器和传动已实测/查铭牌，config 已同步）：

   | 逻辑轴 | 每圈脉冲 (Pulse/Rev) | 传动 | config 换算参数 | 换算结果 | 状态 |
   |--------|----------------------|------|-----------------|----------|------|
   | 轴1 J1 | 25600（驱动器拨码 SW5-8） | 谐波减速 **1:100** | `encoderResolution=25600`、`gearRatio=0.01` | **7111.11 脉冲/度** | 已标定（昨日通过，今日复测） |
   | 轴3 Z  | 25600 | 皮带轮齿比 **40:20（从动:主动）** + 丝杆导程 5mm | `encoderResolution=25600`、`gearRatio=0.5`、`lead=5` | **10240 脉冲/mm**（电机每圈 2.5mm） | 已标定（待验证） |
   | 轴5 夹爪 | 40000（已标定） | 齿轮比 1 + 导程 2mm | `encoderResolution=40000`、`gearRatio=1`、`lead=2` | 已标定 | 驱动器 XINJE DP3L1-224 拨码 SW5-SW8 全 OFF=40000 Pulse/rev，`calibrationPending:false` |

   > **Z 换算推导**：皮带轮齿比 40:20 = 从动/主动 = 2 → 主动(电机)每转 2 圈，从动(丝杆)转 1 圈，故 `gearRatio`(输出转数/电机转数) = 1/2 = **0.5**；电机每圈进给 = 导程 × gearRatio = 5mm × 0.5 = **2.5mm**；每毫米脉冲 = `encoderResolution / 电机每圈进给` = 25600 / 2.5 = **10240 脉冲/mm**。
   > **J1 换算推导**：输出端每圈 = `encoderResolution × microSteps / gearRatio` = 25600 / 0.01 = 2,560,000 脉冲；每度脉冲 = 2,560,000 / 360 ≈ **7111.11**。

3. **网络（关键）**：BoPai 卡 `MC_Open` 在 **wifi 开启时连不上卡**（官方测试软件连 wifi 反而能连；本程序与旧工程一致，需**关闭 wifi**）。**必须关闭 wifi** 后用有线网线连接：`ipconfig` 查 PC 网卡 IP，确认与卡 `192.168.0.1` 同网段；`ping 192.168.0.1` 通；ConfigPage「通信与连接」确认 `pcIp` 为实际网卡 IP。

4. **config.json 切换真机**：
   - `simulation.motionCardType: "Bopai"`（舵机 `servoType: "XRServo"` 维持）
   - 改完需重新构建（POST_BUILD 复制 config）或手动覆盖输出目录 `config.json`。
   - 换算/映射参数在 Connect 时下发：改 `portId`/`encoderResolution`/`axisType` 后需重启程序重连生效。

5. **安全**：手放急停附近；每阶段首次动作都用最小速度小位移；提前确认机械无干涉（J1 臂范围内无遮挡、Z 上下无障碍、夹爪行程内无物）。

6. **日志观察**：`log/creampuff.log`，重点看 `HardwareManager` / `BoPaiCard` / `AxisConverter` 初始化与连接日志、每轴换算值。

## 阶段 0：代码预检（本次已完成，验证即可）

- **BoPaiCard 换算契约修复**：`MoveAbs/MoveRel` 直接接收脉冲（不再内部 ×ppu）；状态回读直接给 `lAxisPrfPos`（脉冲）；`PulsePerUnit` 按 `axisType` + `lead×gearRatio` 计算。物理换算统一在 `HardwareManager`/`AxisConverter` 层。
- **AxisMap config 驱动**：`LoadAxisConfigsFromConfig` 读 `portId` 注入映射表。
- **SimCard 软限位换算**：与 BoPaiCard 同一公式。
- **验收**：SimCard 模式点动/Go/软限位/急停回归通过（构建 EXITCODE=0、仿真存活）。

## 阶段 1：连接 + 使能

- **步骤**：启动 exe → 手动控制页点「使能」（或轴使能）。
- **验收**：
  - J1/Z/夹爪卡轴状态点绿；无 alarm
  - 日志无 `MC_Open failed`
  - 位置显示 0；位置单位 J1=`°`、Z/夹爪=`mm`

## 阶段 2：低速单轴点动 + 换算验证/标定

- **J1 复测验证换算**（25600 脉冲/圈 + 谐波 1:100 → 7111.11 脉冲/度）：设 5°/s 点动 5 秒 → 期望 25°；记录实际增量角，复测 3 次确认误差 <2%。顺带快速回归昨日已通过的点动/Go/停止/回零。
- **Z 验证换算**（25600 + 皮带 0.5 + 导程 5mm → 10240 脉冲/mm）：速度 1mm/s 点动 5 秒 → 理论 5mm；量实测位移，误差 <2% 即通过（参数已定，无需再标定）。
- **夹爪每圈脉冲已标定**（驱动器 XINJE DP3L1-224 拨码 SW5-SW8 全 OFF=40000 Pulse/rev，config `encoderResolution=40000`，`calibrationPending:false`）。**仅验证换算正确性**（可选）：速度 1mm/s 点动 5 秒 → 理论 5mm；若实测≠5mm 优先怀疑 `lead=2mm`（丝杆导程暂定值），据实修正 `lead`。注意行程 ~20mm，别撞死点。
- **方向确认**：点动 + 应正向（J1 顺时针、Z 上升、夹爪张开），反了翻 `direction`。
- **验收**：三轴位移量与设定值误差 <2%；单位标签正确；点动连续无顿挫（BoPai 走卡梯形规划）。

## 阶段 3：软限位

- **步骤**：先实测并修正夹爪（默认 0–20mm 为目测值）与 Z 实际行程到 `limitMin/Max`；低速点动撞向边界。
- **验收**：
  - 接近/到达边界自动停、不越过
  - 状态点橙色 + 底部「轴N 到达软限位」提示
  - 反向点动可离开、提示清除
  - MoveAbs 越界目标被拒绝下发
- **惯性超界后反向离开（2026-08 修复，与 J1 同源）**：夹爪点动夹紧因惯性冲到 `0.2`（>limitMax=0）后，**持续按住「松开」应立即连续运动**（数值从 0.2 一路回落到界内），不再"只能一点一点按"；位置超界时 Go 回界内目标（如 -3）也**应立即执行**。修复记录见 `AGENTS.md`「拦截必须区分运动方向」，真机复测项：
  - 夹紧撞 0 后（数值 0.2），持续按住松开 → 连续回到界内
  - 松开撞 -5 后（数值 -5.2），持续按住夹紧 → 连续回到界内
  - 位置 0.2 时 Go 到 -3 → 正常执行

## 阶段 4：Go 定位（MoveAbs）

- **步骤**：低速（≤10% maxSpeed）下发 J1 90°、Z/夹爪若干绝对定位（限位内多点）。
- **验收**：定位到目标、误差在机械回差内（步进开环注意丢步）；同一目标往返一致；位置显示与量测一致。

## 阶段 5：回零

- **步骤**：确认 BoPai 卡是否接入硬件 Home 开关（接线表已对齐 home1/2/4）。点手动页「回零」。
- **分支**：
  - 有硬件 Home：应找原点后停在零位（`nHomeMode=1` 限位回零）。
  - 无 Home / 回零异常：改走软件回零（`HomeAxis` 回落到软零位 `0`），确认程序不回零不报错。
- **J1 已通过（参考配置）**：`homeDir=0`（反方向搜索）、`homeSns=1`（HOME 高有效，决定搜索方向；真机实测 -1 顺时针、0/1 逆时针）、`homeRapidVel=21.3`（≈3°/s）、`homeLocatVel=7.1`（≈1°/s）。回零动作到位且坐标归零。Z/夹爪按需参考此配置试搜方向。
- **验收**：各轴回到期望零位；日志有 `Home axis N started`。

## 阶段 6：停止 / 急停

- **步骤**：点动中按「停止」→ 应减速停；运动中按「急停」。
- **验收**：
  - 急停后卡轴全部 halt（`MC_Stop`）、状态点变告警/失能
  - 再按「复位/使能」能重新使能
  - 急停后卡不残留运动指令（停止后位置不再变化）

## 阶段 7：状态遥测

- **步骤**：点动 J1/Z/夹爪持续观察手动页位置刷新（50ms 轮询）。
- **验收**：位置平滑实时更新、无卡死/跳变；单位/方向/告警灯与机械实际一致；切页回来状态不丢。

## 阶段 8：异常与回归

- **异常**：运动中拔网线 → 程序**不崩溃**、有错误日志/提示；恢复后重新使能可重连。
- **回归**：把 config 切回 `SimCard`，重跑卡轴核心项（点动/Go/急停/软限位）确认仿真模式无回归。

## 注意事项

- **每阶段验收不通过即停**，先查 `log/creampuff.log` 再定位。
- **Z 每圈脉冲标定**是 Z 后续测试的前提（皮带打滑问题修复后）；J1/夹爪参数已确认（25600/谐波1:100、40000/直连1/导程2）。步进开环无编码器反馈，急停/限位后位置可能与实际漂移，重新回零再继续。
- **自动流程遗留**：`PickCycleController` 仍硬编码卡轴号（0/2/3），与新 `portId` 映射不一致，手动测试完成后需改为走 `HardwareManager`/`AxisMap` 接口再接自动流程。
