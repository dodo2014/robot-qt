# 真机手动控制功能测试 —— 8 阶段流程

> 针对 CreamPuffRobot 真机（BoPai 运动控制卡 + XR 串口舵机）的手动控制功能测试。
> 配套代码修复记录见 `AGENTS.md`「真机接入确定性 bug 修复」。

## 前置准备

1. **接线核对**：BoPai 卡网线接 PC；J2/R 两舵机共连 COM3；J1/Z/夹爪步进接卡对应轴口。
2. **网络**：`ipconfig` 查 PC 网卡 IP，确认与卡 `192.168.0.1` 同网段；`ping 192.168.0.1` 通。
3. **config.json 切换真机**（`config/config.json`）：
   - `simulation.motionCardType: "Bopai"`、`simulation.servoType: "XRServo"`
   - `communication.motionCard.pcIp` → 实际网卡 IP
   - **生效方式**：改完需重新构建（POST_BUILD 复制 config 到输出目录）或手动覆盖输出目录的 `config.json`；运行时 ConfigPage 改动即时生效，但**换算参数在 Connect 时下发，改 pulsesPerRev/axisType 后需重新使能/重连**。
4. **安全**：手放急停附近；每阶段首次动作都用最小速度小位移；提前确认机械无干涉。
5. **日志观察**：`log/creampuff.log`，重点看 `HardwareManager` / `BoPaiCard` / `XRServo` 初始化与连接日志。

## 阶段 1：连接

- **步骤**：启动 exe → 手动控制页点「使能」。
- **验收**：
  - J1/Z/夹爪卡轴状态点绿（已连接）
  - J2/R 两舵机均「已连接」（验证共享串口）
  - 日志无 `Connect failed`/串口占用错误
  - 位置显示 0

## 阶段 2：低速单轴点动 + 标定

- **J1 验证换算**：设 5°/s 点动 + 5 秒，记录增量角；复测 3 次确认 J1=32000/360 换算正确（必要时用机械基准角 90° 复核）。
- **夹爪/Z 标定每圈脉冲**：速度 1mm/s 点动 5 秒 → 理论位移 5mm，量实测位移 d，**每圈脉冲 = 32000 × 5 / d**。改 ConfigPage 电控页对应轴 `pulsesPerRev` → 重新使能 → 复测直至 5mm 实走 5mm。
- **方向确认**：点动 + 应正向（夹爪张开、Z 上升），反了翻 `direction`。
- **验收**：三轴位移量与设定值误差 < 2%；单位标签正确（J1/R 显示 `°`，Z/夹爪显示 `mm`）；软限位待阶段 3 一起修正。

## 阶段 3：软限位

- **步骤**：先修正夹爪软限位（量实际行程，默认 0–20mm 为目测值）与 Z 行程；点动撞向边界。
- **验收**：
  - 接近/到达边界自动停、不越过
  - 手动页状态点橙色 + 底部「轴N 到达软限位」提示
  - 反向点动可离开、提示清除
  - MoveAbs 越界目标被拒绝下发

## 阶段 4：Go 定位（MoveAbs）

- **步骤**：低速（如 10% maxSpeed）下发起 J1 90°、Z/夹爪若干绝对定位。
- **验收**：定位到目标、误差在机械回差内（步进开环注意丢步）；同一目标往返一致；单位换算后脉冲数与 config 公式一致。

## 阶段 5：回零

- **步骤**：点手动页「回零」。
- **验收**：各轴回到零位。**注意**：先确认当前回零实现是软件零位还是硬件 Home 开关（真机若无 Home 开关，确认是否回落软零位 `0` 而非机械原点），无硬件开关时回软零位即可。

## 阶段 6：停止 / 急停

- **步骤**：点动中按「停止」→ 应减速停（或立即停）；运动中按「急停」。
- **验收**：
  - 急停后卡轴全部 halt、J2/R 舵机失力（可自由拨动）
  - 状态点变告警/失能
  - 再按「复位」能重新使能
  - 急停后卡不残留运动指令

## 阶段 7：状态遥测

- **步骤**：点动 J1/Z 持续观察手动页位置刷新（50ms 轮询）。
- **验收**：位置平滑实时更新、无卡死/跳变；单位、方向、告警灯与机械实际一致；切页回来状态不丢。

## 阶段 8：异常与回归

- **异常**：运动中拔 COM3 / 拔网线 → 程序**不崩溃**、有错误日志/提示；恢复后重新使能可重连。
- **回归**：把 config 切回 `SimCard`/`SimServo` 重跑以上 7 阶段核心项（点动/Go/急停/软限位）确认仿真模式无回归。

## 注意事项

- **每阶段验收不通过即停**，先查 `log/creampuff.log` 再定位。
- 阶段 2 标定是后续所有阶段的前提，务必测到位。
- 步进开环系统无编码器反馈，急停/限位后位置可能与实际漂移，重新回零再继续。
