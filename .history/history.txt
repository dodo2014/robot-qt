# Kinematics 重构原则

- 原则 1 等效小臂与强语义 TCP：夹爪直接装在 J4 前方朝下。保留 SetTCP(offsetX, offsetY, offsetZ)；内部 tcpForward_=offsetX、tcpDown_=-offsetZ（offsetY!=0 时 SPDLOG_WARN 忽略 Y 向）；l2_eff = l2_ + tcpForward_。
- 原则 2 甜甜圈工作空间校验：l2_eff 可能大于 l1_，工作空间为中空圆环。r > (l1_+l2_eff)+0.001 或 r < |l1_-l2_eff|-0.001 时目标不可达返回 false；原点物理不可达，删除原点奇点处理。
- 原则 3 Z 轴高度：Z0=撞顶时大臂上表面绝对高度，h1=大臂向下倾斜固定垂直落差，tcpDown_=夹爪向下延伸长度。正解高度 = 电机物理高度 + z0_ - h1_ - tcpDown_；逆解电机物理高度 = 目标尖端高度 - z0_ + h1_ + tcpDown_。
- ConfigPage 运动学 Tab 在 L1/L2/Z0 旁追加 h1（大臂落差）输入框，双向绑定 config.json 的 kinematics.links.h1。

# HomeOffset 逻辑零点机制

- 语义：逻辑角度 = 机械角度 - homeOffset。J1 offset=102°、J2 offset=28°、其余 0。所有界面/软限位/运动学统一使用逻辑坐标。
- 软限位同步偏移：J1 物理 0~110° → limitMin:-102/limitMax:8；J2 物理 0~180° → limitMin:-28/limitMax:152。

# 夹爪机构与业务边界

- 真机结构：夹爪电机轴是短丝杆，螺纹环带夹爪松紧。螺纹环靠近电机=夹紧、远离=松开；从电机轴向看顺时针=松开、逆时针=夹紧。回零默认是夹紧（限位金属片碰电机轴根部开关触发）。
- 软限位 [-5,0]mm 来源：回零后显示 0、松开后显示负值 → limitMin=-5/limitMax=0。
- 业务边界存疑（维持现状继续测试中）：① 夹爪界面按钮与点动方向的对应关系（夹紧应=点动-还是点动+）；② 电机正负向与顺/逆时针对应约定（观察方向）；③ 松开后位置显示负值是否有问题。

# 软限位反向拦截 bug

- 现象：惯性越界（如夹爪冲到 0.2 > max=0）后持续按反向键无反应，只能逐点按回区间；越界后 Go 回界内也被拦。

- 门禁矩阵实现：HardwareManager 新增 IsSystemHomed()/IsAxisHomed()/axisHomed_（无绑定轴恒 true）/homeStateChanged(bool) 信号；MoveAbs 使能门禁后加回零门禁（JOG/回零不受限）；RunSequence/RunSingleAction 加同门禁（报「系统未回零，请先一键回零」）；AutoRunPage 启动按钮初始禁用+homeStateChanged(true) 激活；ProcessPage 单步/执行选中按钮联动+槽内双保险弹窗；ManualControlPage Go 失败提示。
- 完成判定关键设计：HomeAxis 指令下发成功≠已回零（回零异步，指令即返回、运动在后台）——首版「下发即 MarkAxisHomed」导致急停中途误判已回零；修复为完成判定基于实际到位观测：卡轴在 PollCardAxis（homingActive_ && !st.running && 过 1s 保护期）、舵机在 PollServoTelemetry（|逻辑角|≤1°）时 MarkAxisHomed；新增 AbortHoming（仅复位回零中的绑定轴，已完成轴保持）接入 EmergencyStop/DisableAll/StopAxis/StopJog。AGENTS.md 已注明勿回退为「下发即置位」。
- 轴6（挤出）豁免：只接运动卡未接电机——AxisConfig 新增 enabled 字段（默认 true），config Axis_Extruder.enabled=false → LoadAxisConfigsFromConfig 显式 SetBinding(None)（防 AxisMap 默认表兜底），HomeAll 跳过 None 轴；接电机后 config 改回 enabled=true 即恢复，无需改代码。
- 启动崩溃教训：enabled 豁免实现曾写在 Initialize 第 4 步（LoadAxisConfigsFromConfig）内直接写 axisHomed_[i]=true，而 axisHomed_ 第 5 步才 resize → 空 QVector 越界，启动断言崩 QList::operator[] index out of range（qlist.h:518）。**分步初始化时前序步骤禁止访问后续才 resize 的成员容器**。
- 状态：Sim 验证通过；真机复测待做（TEST_RECORD 🟡，最高优先）：启动→使能→一键回零（5 轴）→中途急停→Go 被拒+启动/单步/执行选中全禁→重新完整回零后恢复。

- 需求（用户拍板语义）：夹爪动作下拉（张开/闭合）后新增行程输入框（mm），与手动控制页轴5 Go 完全一致——输入即轴5 绝对目标坐标，「输入什么值就执行什么值」；物理事实 0 = 夹紧、负值 = 松开（闭合向 0 趋近、张开向 -5 逼近）；默认闭合 0.00 / 张开 -3.00；速度等参数映射到轴5。设计经 Plan 代理复核纠正 1 处（越界应拒绝而非 clamp）+ 补 2 处（实时写回、blockSignals）。

- 旧数据迁移注意：process.json 中「关闭夹爪」（156 行）的 isGripperOpen 本为 true → 迁移后默认拿 -3.00（松开），须在界面人工改成 0.00（全库仅 2 个夹爪动作）。

- 执行层：SequenceWorker::ExecuteGripper 重写——取 action.gripperTarget；IsWithinSoftLimits 越界拒绝 + errorOccurred（拒绝而非静默夹紧，与手动页 Go 同源）；速度 = GetMaxSpeed(Gripper)×speedPercent（旧版未传速度走卡内默认）；到位超时从固定 10s 改为 qMax(3000, GetAxisBusyMs×1.2+3000) 动态兜底（低速 10% 走 3mm 需 15s，固定 10s 会误报超时）。

# 构建脚本规范与 LNK1168 自动处理

- Windows 编译：Git Bash 调 cmd 会因引号嵌套/MSYS2 路径转换坏 vcvars 路径，必须用 PowerShell：cmd /c "call vcvars64.bat >nul && ninja CreamPuffRobot"（在 out\build\x64-Debug 下）；Release 用根 build_release.bat。
- bat 必须纯 ASCII（中文注释被 cmd 按 GBK 解析成乱码命令）；ps1 含中文须带 UTF-8 BOM。
- out\smoke\build_debug.bat 与根 build_release.bat 支持 TARGET 环境变量选 target（默认 CreamPuffRobot）；内置 LNK1168 自动处理：构建日志 findstr LNK1168 → taskkill /IM CreamPuffRobot.exe /F → 等 1s 自动重编一次。
- 判编译成败不能只看 exit code（2026-09-02 坑）：ninja 的 stderr 提示 "build log version is too new; starting over"（触发全量重编）会被 PowerShell 当 NativeCommandError 令退出码为 1（假失败）；要看日志里的 [N/N] Linking 行。
- 沙箱/工具链权威编译参考 doc/compile_guide.md（2026-09-01 落盘并首次纳入版本库：MSVC/WinSDK/Qt 真实路径、手工 env + 内联 ninja 编译、tipcheck 编译运行等）。
- PowerShell 执行 git 可避开 Git Bash 偶发 DLL 初始化崩溃（0xC0000142）。
- Git Bash 的 /tmp 路径直接传给 Windows python.exe 会被解析为 d:\tmp（2026-09-01 踩坑）：脚本路径须用 $(cygpath -w /tmp/xxx.py) 转换后再传。
