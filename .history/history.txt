# Kinematics 重构原则（2026-08-20）

- 原则 1 等效小臂模型与强语义 TCP：物理模型已严密验证后彻底重写 Kinematics.h/.cpp，夹爪直接安装在 J4 前方并朝下。保留外部配置接口 SetTCP(offsetX, offsetY, offsetZ) 与 config.json 联动；类内部删除 dx_/dy_/dz_，改用 tcpForward_=0.0（沿小臂 L2 向前）、tcpDown_=0.0（竖直向下物理距离，绝对正数）。
- SetTCP 映射：tcpForward_=offsetX；tcpDown_=-offsetZ（传入 offsetZ 为负表示向下）；offsetY != 0 时 SPDLOG_WARN「当前模型忽略 Y 向 TCP 偏移」。正逆解中小臂有效长度 l2_eff = l2_ + tcpForward_。
- 原则 2 甜甜圈工作空间校验（Annulus Workspace）：l2_eff 可能大于 l1_，工作空间为中空圆环。ikSolve 双向边界检查：r > (l1_+l2_eff)+0.001 或 r < fabs(l1_-l2_eff)-0.001 时目标不可达，打印警告返回 false；彻底删除原 if(r<kEpsilon) 原点奇点处理（原点物理上不可达）。
- 原则 3 Z 轴高度推导：Z0 为撞顶时大臂上表面绝对高度，h1 为大臂向下倾斜固定垂直落差，tcpDown_ 为夹爪向下延伸长度；SetParams(l1xy, l2, z0, h1)。
- 正解：夹爪尖端真实高度 = 电机物理高度 + z0_ - h1_ - tcpDown_；逆解：电机物理高度 = 目标尖端高度 - z0_ + h1_ + tcpDown_（早期无 tcpDown_ 项的表述作废，以此为准）。

# 夹爪机构（真机结构）

- 夹爪电机轴是一根短丝杆，丝杆上有螺纹环，螺纹环带动夹爪松开/夹紧。
- 螺纹环靠近电机 → 夹紧；远离电机 → 松开。从电机轴向看：顺时针=松开、逆时针=夹紧。
- 回零动作默认是夹紧：螺纹环上的限位金属片接触电机轴根部限位开关触发回零。
- 夹爪软限位 -5~0mm 来源：回零后位置显示 0；松开后位置显示负值 → limitMin=-5、limitMax=0。

# 软限位反向拦截 bug（已修复并真机验证）

- 现象：点动夹紧惯性越过 0 到 0.2 后持续按「松开」无反应，只能逐点按回 [-5,0] 区间；反向同理；越界后 Go 到界内值也无反应。
- 根因：软限位拦截未区分运动方向（与 J1 曾遇问题同源）——惯性越界后朝边界内运动的请求也被拦截。
- 修复：按运动方向判断，仅拦截仍朝越界方向运动的动作，朝边界内运动放行。已真机验证并记账。
