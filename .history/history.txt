- 原则 1 等效小臂模型与强语义 TCP：物理模型已通过严密验证，彻底重写 Kinematics.h/.cpp。夹爪直接安装在 J4 前方并朝下。
- 保留外部配置接口 void SetTCP(double offsetX, double offsetY, double offsetZ) 以便与 config.json 联动。类内部删除 dx_/dy_/dz_，改用 tcpForward_ = 0.0（沿小臂 L2 向前）、tcpDown_ = 0.0（竖直向下物理距离，绝对正数）。
- SetTCP 映射：tcpForward_ = offsetX；tcpDown_ = -offsetZ（假设传入 offsetZ 为负表示向下）；若 offsetY != 0 用 SPDLOG_WARN 打印「当前模型忽略 Y 向 TCP 偏移」。正逆解中小臂有效长度 l2_eff = l2_ + tcpForward_。
- 原则 2 甜甜圈工作空间校验（Annulus Workspace）：l2_eff 可能大于 l1_，工作空间为中空圆环。ikSolve 必须双向边界检查：r > (l1_ + l2_eff) + 0.001 或 r < fabs(l1_ - l2_eff) - 0.001 时目标不可达，打印警告并返回 false。彻底删除原 if (r < kEpsilon) 原点奇点处理（原点物理上不可达）。
- 原则 3 Z 轴正逆解高度推导：Z0 为撞顶时大臂上表面绝对高度；h1 为大臂向下倾斜固定垂直落差；tcpDown_ 为夹爪向下延伸长度。SetParams(double l1xy, double l2, double z0, double h1)。
- 正解：夹爪尖端真实高度 = 电机物理高度 + z0_ - h1_ - tcpDown_；逆解：电机物理高度 = 目标尖端高度 - z0_ + h1_ + tcpDown_。（早期表述无 tcpDown_ 项，以含 tcpDown_ 推导为准。）

- 软限位随 HomeOffset 同步偏移（用户明确要求）：J1 物理 0~110° → 逻辑 limitMin:-102.0 / limitMax:8.0；J2 物理 0~180° → 逻辑 limitMin:-28 / limitMax:152。config.json 默认值已同步更新。
- 回零后逻辑位置为 -offset；所有逻辑坐标经硬件层单点转换（MoveAbs 下发 机械=inv?-(逻辑+off):(逻辑+off)、GetPosition 回读减 offset），不得在别处再加减偏移。实现全部落在 HardwareManager 门面层，AxisConverter 保持纯机械坐标↔脉冲不感知偏移。

# 夹爪机构（真机结构）

- 夹爪电机轴是一根短丝杆，丝杆上有螺纹环，螺纹环带动夹爪松开/夹紧。
- 螺纹环靠近电机 → 夹紧；远离电机 → 松开。从电机轴向看：顺时针=松开、逆时针=夹紧。
- 回零动作默认是夹紧：螺纹环上的限位金属片接触电机轴根部限位开关触发回零。
- 夹爪软限位 -5~0mm 来源：回零后位置显示 0；松开后位置显示负值 → limitMin=-5、limitMax=0。

# 软限位反向拦截 bug（已修复并真机验证）

- 现象：点动夹紧惯性越过 0 到 0.2 后持续按「松开」无反应，只能逐点按回 [-5,0] 区间；反向同理；越界后 Go 到界内值也无反应。
- 根因：软限位拦截未区分运动方向（与 J1 曾遇问题同源）——惯性越界后朝边界内运动的请求也被拦截。
- 修复：按运动方向判断，仅拦截仍朝越界方向运动的动作，朝边界内运动放行。已真机验证并记账。
