# TR-070 舵机未上电误报已连接（2026-09-04，真机通过，提交 16a6cc3）

- 现象：舵机仅插 USB 未上电，启动软件 UI 显示「舵机: 已连接」。附带 bug（上电日志实证）：`WriteUserData id=1` 两次、`Servo id 1 online` 两次，id=0 从未被探测——Initialize/ReconnectServos 先 Connect 后 SetServoId，Connect 内用默认 id=1 做 Ping/WriteUserData(addr=44)。
- 根因三层：① XRServo::Connect 串口打开成功即返回 true（Ping 失败仅 WARN）；② IsConnected() 语义=串口句柄有效（真实在线在 IsOnline()，未接入判定）；③ HardwareManager::IsServoConnected() 只查串口级 → UI 标签/EnableAll 门禁/PollTick 边沿检测全基于假"已连接"。
- 修复（HardwareManager 单文件三处）：IsServoConnected 收紧为「串口打开 且 所有已创建舵机 IsOnline()」（SimServo 的 IsOnline==connected_，仿真不受影响）；Initialize/ReconnectServos 中 SetServoId/SetSpeed 移到 Connect 之前。
- 上电自动恢复无需重启：走既有「Ping ok skip reconnect」+ PollTick 边沿广播 connectionChanged 链路，~2s 内 UI 变绿。
- 已知开口：软件开着时上电、经 skip-reconnect 路径恢复的不重写 addr=44 accel 参数（舵机用户数据预期掉电保持）；真机点动若顿挫回归，再在恢复边沿补写。

# Kinematics 重构原则

- 原则 1 等效小臂与强语义 TCP：保留 SetTCP(offsetX, offsetY, offsetZ)；内部 tcpForward_=offsetX、tcpDown_=-offsetZ（offsetY!=0 时 WARN 忽略）；l2_eff = l2_ + tcpForward_。
- 原则 2 甜甜圈工作空间校验：r > (l1_+l2_eff)+0.001 或 r < |l1_-l2_eff|-0.001 时不可达返回 false；原点物理不可达，删除原点奇点处理。
- 原则 3 Z 轴高度：正解高度 = 电机物理高度 + z0_ - h1_ - tcpDown_；逆解电机物理高度 = 目标尖端高度 - z0_ + h1_ + tcpDown_。ConfigPage 运动学 Tab 有 h1 输入框双向绑定 kinematics.links.h1。

# HomeOffset 逻辑零点机制

- 逻辑角度 = 机械角度 - homeOffset。J1 offset=102°、J2 offset=28°、其余 0。界面/软限位/运动学统一逻辑坐标。
- 软限位同步偏移：J1 limitMin:-102/limitMax:8；J2 limitMin:-28/limitMax:152。
- 单一转换点在 HardwareManager 门面层；AxisConverter 纯机械↔脉冲不感知偏移，不得在别处再加减。
